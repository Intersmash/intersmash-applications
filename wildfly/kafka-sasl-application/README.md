# Intersmash Applications - WildFly + Apache Kafka (SASL)

A WildFly/JBoss EAP 8.x application which is provisioned by the `wildfly-maven-plugin` and that uses a remote Apache Kafka service for Messaging via MicroProfile Reactive Messaging, with SASL authentication enabled.

The WildFly/EAP Maven plugin is configured to build the application and trimmed server, based on required feature packs.
